# 🏦 CodeAlpha Banking System

A C++ **Banking System** developed as part of the **CodeAlpha C++ Programming Internship**.

## 📌 Project Overview

This project is a console-based Banking System implemented in C++. It is designed to manage customers and bank accounts while providing basic banking operations such as deposits, withdrawals, fund transfers, and transaction tracking.

The project uses separate classes for **Customer, Account, and Transaction** to organize the banking operations and information.

## ✨ Key Features

- Customer management
- Account creation and management
- Customer and account information
- Deposits
- Withdrawals
- Fund transfers
- Transaction recording
- Transaction history
- Recent transaction viewing
- Account balance display
- Transaction details

## 🧩 Main Classes

### `Customer`

The `Customer` class is used to manage customer-related information and customer accounts.

### `Account`

The `Account` class is used to manage bank account information and account balance.

It supports:

- Deposits
- Withdrawals
- Fund transfers
- Account information

### `Transaction`

The `Transaction` class is used to record and manage transaction information.

It supports the tracking of banking activities such as:

- Deposits
- Withdrawals
- Fund transfers

## 👤 Customer Management

The system provides functionality to create and manage customers.

Customer information is maintained as part of the banking system so that accounts and transactions can be associated with the appropriate customer.

## 🏦 Account Management

The system allows accounts to be created and managed for customers.

Account information and balance are maintained and can be displayed to the user.

## 💰 Deposit

The system provides a deposit operation for adding money to an account.

When a deposit is performed, the account balance is updated and the transaction is recorded.

## 💸 Withdrawal

The system provides a withdrawal operation for removing money from an account.

The account balance is updated and the withdrawal transaction is recorded.

## 🔄 Fund Transfer

The system supports transferring funds between accounts.

A transfer updates the relevant account balances and records the transaction activity.

## 📜 Transaction History

The system records banking transactions and allows users to view transaction history.

Recent transactions can also be displayed to review the latest account activity.

## 💳 Account Information

The system displays account-related information, including:

- Account details
- Current balance
- Transaction information

## 🔄 How the System Works

1. A customer is created and managed by the system.
2. An account is created and associated with the customer.
3. Account information and balance are maintained.
4. Money can be deposited into the account.
5. Money can be withdrawn from the account.
6. Funds can be transferred between accounts.
7. Banking transactions are recorded.
8. Transaction history and recent transactions can be viewed.
9. Account information, balance, and transaction details can be displayed.
